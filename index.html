Privacidad como argumento de producto

La propuesta local-first permite hablar de control de datos, ejecución propia y dependencia reducida de servicios externos sin prometer aislamiento absoluto.

  • Assets servidos desde el paquete local.
  • Sin fuentes remotas ni librerías de animación externas.
  • Degradación visual limpia si JavaScript está deshabilitado.
  • Contenido preparado para demo comercial y entrega ZIP.
